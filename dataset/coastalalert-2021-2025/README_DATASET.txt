COASTALERT — DATASET SAJA (2021–2025)

Isi paket ini hanya file data dan dokumen pendukung, bukan seluruh source code aplikasi.

File:
- spots.json: 11 catatan awal yang mengikuti struktur objek spots di proyek COASTALERT.
- reports.json: array kosong; tidak memasukkan laporan warga sintetis.
- sumber_dataset.csv: daftar sumber dan catatan verifikasi untuk diperiksa manusia.
- README_DATASET.txt: dokumen ini; tidak ada file instruksi tambahan di paket ini.

PENTING:
1. 8 catatan rob bersumber dari tabel artikel Agustina dkk. (2025) dan lokasi yang dilaporkan masih administratif/kota; koordinat rob di spots.json adalah pin perkiraan untuk preview saja, bukan koordinat kejadian terverifikasi.
2. 3 catatan abrasi merupakan laporan/berita terkait kawasan Pulau Baai tahun 2021, 2024, dan 2025. Berita 2024 dan 2025 bisa merujuk masalah berkelanjutan yang sama, jangan otomatis dihitung sebagai dua kejadian independen. Koordinat adalah referensi kawasan, bukan titik pengukuran abrasi.
3. Kategori diset 'Belum diverifikasi'. Jangan menampilkan hitungan kategori Rendah/Sedang/Tinggi sampai ada ambang dan sumber yang sah. Jangan menyimpulkan tingkat rob hanya dari curah hujan.
4. Dataset ini belum mengandung kejadian rob terverifikasi untuk 2025; jangan mengarang baris baru.
5. Jangan menghitung banjir biasa sebagai rob kecuali sumber secara jelas mengidentifikasikannya sebagai rob.

7. Berita abrasi 2021: https://bengkulu.antaranews.com/berita/141996/abrasi-parah-sekitar-lentera-merah-pulau-baai-kabel-listrik-jatuh
